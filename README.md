# E-Ticketing Helpdesk (UTS)

Proyek Flutter untuk simulasi sistem tiket helpdesk dengan role-based access.

## Role Login
- Admin: login dengan username `admin`
- Helpdesk: login dengan username `helpdesk` atau `staff`
- User: login dengan username selain nilai di atas

## Fitur Utama
- Login, register, reset password (UI)
- Dashboard statistik tiket dinamis
- Buat tiket baru (User/Admin)
- Lihat tiket berdasarkan role
- Detail tiket, komentar, dan update status (Helpdesk/Admin)
- Profil pengguna, ganti tema, logout
